Import Order (Queue for Receiving)

Upload a Sales Order / Packing Slip file (PDF or TXT) as soon as it comes in — before the shipment physically arrives. It goes into a queue. When the warehouse crew opens Receive Order, they can pick this file from a dropdown to pull in the extracted items, or leave it on Manual Entry if nothing is queued. If the shipment is received before this date, it's flagged as received early on reports and order details. Leave blank if you don't have an estimate yet.
